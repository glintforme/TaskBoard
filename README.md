# 悬浮任务板（用户可视化自定义任务列表）

完全使用deepseek harness实现的一个任务列表。
一个纯 Python 标准库实现的桌面任务管理软件（**零第三方依赖**，tkinter + http.server + sqlite3）：

- **桌面悬浮窗**：常驻桌面置顶，显示 日常/周常/月常 任务数与完成统计，并列出**今日待完成任务标题**（字号加大，最多显示 10 条 + 剩余统计，窗口高度随任务数自动增高）；点击展开任务明细并逐条完成；**可任意拖动、边缘拖拽缩放**（手动调整的尺寸不会被自动适配回弹，任务数量变化后恢复自动适配）；
- **吸附隐藏到侧边**：把悬浮窗**拖到屏幕右缘附近即自动吸附隐藏**，只露出提示条，**点击提示条即可恢复原位**；
- **背景透明化**：整窗透明度可调（默认 72%，透见桌面）；可**导入自定义背景图片**（PNG/GIF/JPG，自带透明度调节，默认透至桌面可见）。背景图作为壁纸 **cover 自适应**（彩色图像全铺满悬浮窗、无黑边，随窗口拖拽缩放实时重采样跟随）、**始终置底不遮挡内容**，显示在**界面1 / 界面2（含任务详情展开）/ 后台设置页**（设置页壁纸与悬浮窗同步，透明度自动联动）；**搜索面板不显示背景图**；
- **底部功能栏（四个统一大小的圆形按钮，靠右，跟随悬浮窗）**：
  - **🔍 放大镜（最左）**：搜索全部任务——点击后悬浮窗**左侧**展开搜索面板（搜索面板是悬浮窗的**子窗口**，随悬浮窗移动；**拖动面板不会改变悬浮窗大小**，只有鼠标移到面板自身边框才能拖拽缩放面板，悬浮窗也只能通过自己的边框缩放；面板带 **✕ 关闭**按钮；打开即自动加载全部任务；搜索框**即时搜索**（输入即搜、防抖 300ms）或回车搜索；**分类筛选为 4×2 自适应网格**（全部/日常/今日/明日/周常/月常/已完成/未完成，随面板宽度等宽拉伸）；**结果区可滚动**（内容超出面板高度时滚动条查看全部）、**分页显示**（每页 10 条，翻页自动回到顶部），每项显示标题、完成状态，**仅已完成任务显示完成时间**；快速切换分类/搜索不会串扰（过期响应自动丢弃））；
  - **扳手**：打开后台设置页面 / 查看历史完成任务；
  - **图片**：窗口透明度 / 背景图片透明度 / 导入背景图片 / 移除背景图片；
  - **齿轮**：还原到原来位置 / 开机自启动 / 游戏模式 / 退出；
- **刷新按钮**：悬浮窗折叠态与展开态标题栏上的「⟳」按钮，点击立即刷新数据（如「–」最小化按钮一样的小按钮）；
- **最小化到系统托盘**：点「–」隐藏为托盘图标，点击图标恢复；
- **隐藏到侧边 / 游戏模式**：全屏自动隐藏 / 拖拽吸附隐藏，点击提示条还原；
- **游戏模式**：检测到全屏应用（游戏/全屏视频）自动隐藏到侧边，切回桌面自动还原；
- **任务提醒**：为任务设置「提醒时间」，到点**响铃 + 弹窗**提醒；弹窗**显示在悬浮窗上方**，带「✕」关闭按钮；可设置「截止时间」，逾期标红；
- **开始/截止时间**：任务可编辑开始与截止时间；**未设开始时间按创建（编辑）时间开始，未设截止时间按开始后 24 小时截止**；折叠态悬浮窗显示**截止倒计时（天-时-分-秒，每秒刷新）**，展开态点标题可见开始/截止时间；
- **未完成数**：非日常任务到达截止时间仍未完成 → 计入「未完成数」（设置页与悬浮窗同步显示）；日常任务每天完成即可，**不计入未完成数**；
- **任务编辑**：设置页每条任务带「编辑」按钮（标题/备注/类型/开始/截止/提醒均可修改，AI 生成的任务同样可编辑）；
- **后台设置页面**：本地 Web 界面（默认 `http://127.0.0.1:39999`），可自由设定今日/明日/周内/月内任务，可删除、搜索；
- **SQLite 本地保存**：所有任务与完成记录保存到指定路径的 SQLite 数据库（路径可改，自动迁移）；
- **AI 生成任务**：不知道今天做什么？让 AI 按你的实际情况生成今日/明日/周内/月内任务供勾选保存。

## 快速开始

**方式一（推荐）**：双击桌面上的「悬浮任务板」快捷方式（可运行 `创建桌面快捷方式.bat` 生成），或双击 `start.bat`。

**方式二**：命令行

```bat
python app\main.py              :: 启动悬浮窗 + 后台服务（端口 39999）
python app\main.py --no-gui     :: 只启动后台服务（无悬浮窗）
```

启动后屏幕出现悬浮窗。浏览器打开 **http://127.0.0.1:39999** 进入后台设置页面
（同一 WiFi 下手机/平板可用 `http://局域网IP:39999` 访问，页面已做移动端适配）。

> 首次启动若系统防火墙弹窗，请允许 Python 通过专用/公用网络，以便局域网设备访问。
> 若双击 `start.bat` 无反应，请检查是否被安全软件拦截，或改用桌面快捷方式/命令行启动。

## 悬浮窗使用

| 操作 | 功能 |
| --- | --- |
| **左键单击** | 展开 / 收起任务明细（展开后每条任务带「完成」按钮） |
| **点击任务标题** | 展开该任务完整内容（全文/备注/截止/提醒），窗口自动适配大小；再点收起 |
| **按住拖动** | 随意拖动窗口位置（位置自动记忆） |
| **拖到屏幕右缘** | **自动吸附隐藏到侧边**，只露出提示条；**点击提示条恢复原位** |
| **边缘拖拽** | 鼠标移到窗口四边/四角（出现双向箭头）按住拖动即可缩放；**手动调整的尺寸不会被回弹**（任务数量变化后自动恢复适配） |
| **自适应显示** | 展开时窗口高度自动匹配任务数量与换行后的内容（上限 85% 屏幕，超出滚动）；长文本自动换行，把窗口拖窄内容会自动重排不裁切 |
| **圆形功能按钮** | 悬浮窗**右下方**三个统一大小的圆形按钮（从左到右）：**扳手**（打开设置页/查看历史）、**图片**（窗口透明度/背景图片透明度/导入与移除背景图）、**齿轮**（还原位置/自启动/游戏模式/退出）；**同一时间只展开一个面板**，点击其他按钮自动收起；面板固定大小、跟随悬浮窗移动 |
| **行内截止倒计时** | 折叠态（界面1）两列表格（表头「今日待完成｜截止时间」，任务标题与倒计时逐行对应）、展开态（界面2）每条任务右侧均显示截止倒计时：无天数格式 `h:m:s`，有天数 `N天hh:mm:ss`，逾期变红「已逾期」；每秒刷新；日常任务不显示；**展开详情时文本自动为右侧倒计时预留空间，互不遮挡**；倒计时标签固定宽度、仅更新可视区，**大量任务（数百条）也不卡顿** |
| **「×」关闭按钮** | 界面1/界面2 右上角的「×」：点击弹出确认框（**最小化到托盘 / 退出程序**），可勾选「下次不再询问，直接执行所选操作」；已设置后再次点击 × 直接执行 |
| **界面2分区块** | 展开态按「今日/明日/周常/月常」分区块显示，点击分区标题展开/收起该块任务（今日默认展开，其余收起） |
| **位置记忆** | 悬浮窗位置始终跟随用户：拖动后自动保存，退出再打开恢复到用户放置的位置（支持多显示器负坐标）；设置页保存设置不会覆盖已保存的位置 |
| **「⟳」刷新按钮** | 悬浮窗折叠态与展开态标题栏上的小刷新按钮，点击立即刷新任务数据 |
| **「–」最小化按钮** | 隐藏到**系统托盘**（气泡提示），点击托盘图标恢复 |
| **折叠态** | 显示统计 + **今日待完成任务标题**（字号 9pt，最多显示 10 条 + 剩余条数，窗口随任务数增高） |
| **背景透明化** | 选项面板中拖动「窗口透明度」滑块（30%~100%，默认 72%）即透见桌面 |
| **背景图片** | 选项面板「导入背景图片」（PNG/GIF/JPG）→ 作为壁纸 **cover 自适应**（彩色图像全铺满、无黑边，拖拽缩放实时跟随）、**置底不遮挡内容**；显示于界面1/界面2/后台设置页（搜索面板不显示）；可用「背景图片透明度」滑块调节；「移除背景图片」恢复默认 |

> 最小化到托盘后程序仍在后台运行：任务提醒照常响铃弹窗；托盘图标左键恢复窗口，右键打开选项面板。

折叠态显示：`日常 N · 周常 N · 月常 N` 与 `今日完成 X · 总完成 Y`，每 5 秒自动刷新。

## 任务提醒与截止时间

在后台设置页添加任务时，可设置：

- **▶ 开始时间**：默认**系统当前时间**（可自定义）；不填则按创建（编辑）时间开始；
- **⏰ 截止时间**：默认**开始时间 24 小时后**（即当前时间的次日同时刻，可自定义）；超过截止未完成 → 标红「已逾期」并计入**未完成数**；
- **🔔 提醒时间**：到点后程序自动**响铃 + 弹窗**（弹窗显示在悬浮窗上方，带「✕」关闭按钮；设置页打开时浏览器也会响铃提示）；同一天只提醒一次。

桌面悬浮窗折叠态（界面1）为**两列表格**：表头行「今日待完成 | 截止时间」独占一行，下方每条任务标题与截止倒计时**逐行一一对应**（无天数格式 `h:m:s`，有天数 `N天hh:mm:ss`，逾期红色「已逾期」，无截止显示「—」）；有逾期时底部显示「⚠ 未完成 N 项」；每秒刷新。展开态（界面2）任务列表每条任务**右侧**同样显示截止倒计时，点击任务标题可查看完整内容与**开始/截止时间**。

**旧任务截止时间迁移**：以前部署的没有截止时间的任务，首次启动时统一设置为「开始（或创建）时间 + 24 小时」（一次性迁移，之后手动清空截止时间不会被重复覆盖）。

**未完成数**：仅统计**非日常任务**到达截止时间仍未完成的（日常任务只需每天完成，不计入未完成数）。

**编辑任务**：设置页任务卡片点「编辑」→ 弹窗中修改标题/备注/类型/开始时间/截止时间/提醒时间，保存即时生效；AI 生成的任务同样支持编辑。

提醒由桌面悬浮窗每 5 秒轮询触发，需保持程序运行；若使用 `--no-gui` 模式则只有浏览器端提示。

## 后台设置页面

顶部标签页：

- **今日任务**：添加「今日任务（仅今天）」或「日常任务（每天重复）」；点击「完成」按钮即保存完成记录；
- **明日任务 / 周常任务 / 月常任务**：规划各时间范围的任务；
- **全部任务**：搜索 + 类型筛选，删除不需要或重复设置的任务；
- **历史完成**：全部完成记录（按日期分组），可撤销完成或删除记录；
- **AI 生成**：填写你的实际情况 → 选择生成范围（**日常**/今日/明日/周内/月内）与数量 → 选择模型 → 生成后可勾选保存；保存后仍可逐条编辑；
- **设置**：修改数据库保存路径（自动迁移数据）、端口（默认 39999）、监听地址、开机自启动。

任务数据在每次添加/完成/删除/编辑时**即时写入 SQLite**。

## AI 生成任务（环境变量配置）

程序从**系统/用户环境变量**读取 API Key（openai 暂不可用，会被跳过）：

| 环境变量 | 模型 ID | 服务商 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY`（或 `deepseek-apikey`） | `deepseek-v4-flash` | DeepSeek |
| `MOONSHOT_API_KEY`（或 `KIMIK3_API_KEY` / `kimik3-apikey`） | `kimi-k3` | Kimi（月之暗面） |
| `GOOGLE_API_KEY`（或 `GEMINI_API_KEY` / `gemini-apikey`） | `gemini-3.7flash` | Google Gemini |
| `OPENAI_API_KEY` | — | 暂不可用 |

设置方法（“系统变量” 或 `setx` 均可）：

```bat
setx DEEPSEEK_API_KEY "sk-你的密钥"
setx MOONSHOT_API_KEY "sk-你的密钥"
setx GOOGLE_API_KEY "你的密钥"
```

**关键特性**：
- 设置/修改系统变量后**无需重启应用**——程序会自动从注册表（用户+系统环境）读取最新 Key；
- 自动选择顺序为 **DeepSeek → Kimi → Gemini**（DeepSeek / Kimi 国内可直连，Gemini 可能受网络环境影响，可在 AI 页手动指定模型）；
- 某个模型调用失败/超时会**自动降级为内置模板**生成，并明确提示原因，功能不中断；
- 未配置任何 Key 时直接使用内置模板。

## 常见问题

- **端口 39999 被占用**：提示后请先关闭占用程序，或用 `python app\main.py --port 40000` 换端口；
- **局域网打不开**：检查防火墙是否放行 Python，或确认手机与电脑在同一网络；
- **AI 提示未检测到 Key**：确认环境变量名正确（见上表），改完后无需重启；若仍不识别，检查变量值是否为空；
- **AI 提示调用失败/超时**：当前网络可能无法访问该模型（如 Gemini 需能访问 Google），请在 AI 页手动选择 DeepSeek 或 Kimi；
- **提醒不响**：确认程序在运行、提醒时间已到、任务当天未完成；悬浮窗被贴边隐藏时提醒弹窗仍会正常弹出。
